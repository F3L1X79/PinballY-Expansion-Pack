# Sound credits

The pack's default sounds, all from [Freesound](https://freesound.org) under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain,
no attribution required; credited here with thanks). `confetti.wav` and
`fireworks.wav` were converted to 16-bit stereo.

| File | Played | Source | Author |
|---|---|---|---|
| `launch.mp3` | when a table launches | [529817](https://freesound.org/people/dastudiospr/sounds/529817/) | dastudiospr |
| `achievement.wav` | with each Achievement Toast | [813177](https://freesound.org/people/its-slava/sounds/813177/) | its-slava |
| `profile_greeting.mp3` | with each Profile Greeting | [323437](https://freesound.org/people/Alivvie/sounds/323437/) | Alivvie |
| `confetti.wav` | when a Confetti Shower starts | [764054](https://freesound.org/people/ShangusBurger/sounds/764054/) | ShangusBurger |
| `fireworks.wav` | when the Fireworks start | [435729](https://freesound.org/people/SamuelGremaud/sounds/435729/) | SamuelGremaud |

Your own sounds go in `local/`, which git ignores; point `.env.local` at them
(see `.env.example`).
